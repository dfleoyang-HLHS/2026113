# 113 班座位表

## 功能特色

- 6 排 × 6 列座位表
- 滑鼠拖放 / 手機長按拖曳調整座位
- 男生淺藍色、女生淺粉紅色
- 本地儲存 + GitHub 雲端同步
- **下載 Excel 座位表**（含座位配置與學生明細）
- **列印 / 另存 PDF**（可直接存成 PDF 或圖片）

## 使用方式

1. 上傳 `index.html` 和 `config.json` 到 GitHub。
2. 啟用 GitHub Pages。
3. 開啟網頁，按「設定」輸入 token。
4. 拖曳座位調整。
5. 按「下載 Excel 座位表」或「列印 / 存 PDF」匯出檔案。

## 手機操作

- **長按**學生座位約 0.5 秒。
- **拖曳**到目標位置。
- **放開**即可完成交換。

## 匯出檔案

### Excel 座位表

- 包含「座位表」與「學生明細」兩個工作表。
- 可直接編輯、列印或轉 PDF。

### 列印 / 存 PDF

- 按「列印 / 存 PDF」按鈕。
- 在列印視窗中選擇：
  - **另存為 PDF**：儲存為 PDF 檔案。
  - **儲存為圖片**：部分瀏覽器支援存成圖片。
